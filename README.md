# thinput+
　東方Project Windows版でゲーム内に入力を表示するツールです。
東方紅魔郷から東方錦上京に対応しています(現在東方獣王園, バレットフィリア達の闇市場のみ未対応)  
　Touhou Input Displayからインスピレーションを受けて作成しました。
(Touhou Input Displayを逆コンパイルしたりと解析はしておりません)
## 使い方
### thinput+.exe
　本体といえば本体です。本家様Touhou Input Displayのように独立したウィンドウで動作します。  
こっちはあまり使わないかも...
### thinput_injector.exe
　対応した東方原作を開いている状態で実行することでオーバーレイとして動作します。フルスクリーンでも動作します。  
  
　東方本体があるフォルダにdgVoodooのD3D9.dllを置く必要があります。  

`MS/x86/D3D9.dll` をお使いください。 [dgVoodooはコチラから](https://github.com/dege-diosg/dgVoodoo2)
> 注: thinput+本体はゲームの実行ファイルのあるディレクトリに置く必要はありません。  
   
> ※: ~~なんでかは私にもわかりませんが試しにdgVoodooを導入するとちゃんと動作したんです(ぉ~~
#### ゲーム中の設定について
　iキーを押すことで入力表示の位置,大きさを変えることが出来ます。
