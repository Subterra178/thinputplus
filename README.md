# thinput+
　東方Project Windows版でゲーム内に入力を表示するツールです。
東方紅魔郷から東方錦上京に対応しています(現在東方獣王園, バレットフィリア達の闇市場のみ未対応)  
　Touhou Input Displayからインスピレーションを受けて作成しました。
(Touhou Input Displayを逆コンパイルしたりと解析はしておりません)
## 使い方
### thinput+.exe
　本体といえば本体です。本家様Touhou Input Displayのように独立したウィンドウで動作します。  
こっちはあまり使わないかも...
### thinput_injector.exe
　オーバーレイとして動作します。フルスクリーンでも動作します。  
  
> 注: thinput+はゲームの実行ファイルのあるディレクトリに置く必要はありません

#### ゲーム中の設定について
　iキーを押すことで入力表示の位置,大きさを変えることが出来ます。
